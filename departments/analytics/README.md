# Analytics

Tracks and reports on content performance across YouTube, Instagram and TikTok. Full role, KPIs and tools: [`docs/departments/analytics.md`](../../docs/departments/analytics.md).

| Folder | Holds | Cadence |
|--------|-------|---------|
| `performance/` | Views, watch time, retention, engagement, CTR | Daily |
| `audience/` | Demographics, geography, viewer behavior, segments | Weekly |
| `growth/` | Follower growth, reach, viral and trend analysis | Weekly |
| `reports/` | Executive and campaign-specific reports | Monthly |

## Handoffs
Analytics hands findings to other departments rather than receiving an episode. Before sharing: data attached, insights documented, recommendations and trends stated.

## Conventions
- Report with the episode ID (`EP001`) so figures can be matched to the episode's metadata.
- Keep text and data files (Markdown, CSV, JSON) here. Screenshots and exported images are gitignored.
- Analytics is not an ethics-gated stage, but numbers must not be selectively framed. State the date range and source for every figure.
