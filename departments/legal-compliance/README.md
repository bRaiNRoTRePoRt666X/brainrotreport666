# Legal & Compliance

Keeps content legally compliant and ethically sound. Full role, KPIs and tools: [`docs/departments/legal-compliance.md`](../../docs/departments/legal-compliance.md). Campaign ethics: [`docs/ethics/campaign-principles.md`](../../docs/ethics/campaign-principles.md).

| Folder | Holds |
|--------|-------|
| `contracts/` | Talent, contractor and collaboration agreements, release forms |
| `rights/` | Music, stock footage and image licenses, usage permissions |
| `privacy/` | GDPR/CCPA compliance and data-handling documents |
| `ethics/` | Ethics guidelines and review records |
| `disclaimers/` | Templates for sponsor, affiliate, content-warning and legal disclaimers |

## Review checkpoints
Every episode needs all four:
- [ ] Script ethics review (Creative handoff)
- [ ] Rights clearance (Production handoff)
- [ ] Final compliance check (Distribution handoff)
- [ ] Disclosure verification (before publish)

Support runs across all stages. See [`docs/workflows/handoff-process.md`](../../docs/workflows/handoff-process.md) for which review gates which handoff.

## Conventions
- Signed contracts and licenses are often PDFs or images, which are gitignored. Track a reference (parties, date, location of the original) in text.
- Do not commit personal data or signed originals.
